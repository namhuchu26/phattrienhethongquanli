# Hệ thống quản lý nhân sự - Nhóm 16

Mã nguồn ở thư mục **hrms**. Nhấp đúp **CHAY_HE_THONG.bat** để khởi động, rồi truy cập **http://127.0.0.1:3000**.

Tài khoản quản trị mẫu: **admin** / **Demo@12345**.

Yêu cầu Node.js 24 trở lên. Không cần cài thêm thư viện. Dữ liệu SQLite tự tạo và lưu trên máy.

- [Hướng dẫn chạy, tài khoản và chức năng](hrms/README.md)
- [Thiết kế và đối chiếu với bốn tài liệu](hrms/docs/THIET_KE.md)
- [Lược đồ cơ sở dữ liệu](hrms/docs/schema.sql)

Bản **BAN_NOP_QLNS.zip** chứa mã nguồn, hướng dẫn, script khởi động và bốn tài liệu phân tích ban đầu, không chứa cơ sở dữ liệu hay phiên đăng nhập tại máy.
